# کاتالوگ واقعی و ورود به WooCommerce

## دامنه داده‌ها

فهرست اولیه شامل محصولات پارس مهر، نیپون و کاسپین است. نام محصول، کد محصول و بسته‌بندی فقط در حدی درج شده که در فهرست‌های عمومی فروشندگان/تولیدکننده مشاهده شده است. برای هر رکورد نشانی منبع نگهداری می‌شود.

## سیاست عدم جعل داده

- قیمت، موجودی، SKU کارخانه‌ای تأییدنشده، تصویر محصول، رنگ‌بندی و ادعاهای فنی فاقد منبع ساخته نمی‌شوند.
- SKUهای با پیشوند `BAM-` شناسه داخلی فروشگاه هستند، نه کد کارخانه.
- وزن/حجم نامشخص صریحاً نامشخص باقی می‌ماند.
- محصولات تازه با وضعیت `draft` ایجاد می‌شوند؛ تا زمانی که قیمت، موجودی، بسته‌بندی و تصویر مجاز کنترل نشده‌اند در فروشگاه عمومی نمایش داده نمی‌شوند.
- اجرای دوباره import با SKU داخلی تکرار محصول ایجاد نمی‌کند و قیمت/موجودی دستی موجود را بازنویسی نمی‌کند.

## اجرا روی پایگاه داده واقعی فروشگاه

پس از فعال بودن WordPress و WooCommerce، در ریشه نصب WordPress اجرا شود:

```bash
wp bamero catalog import
```

این فرمان از CRUD رسمی WooCommerce استفاده می‌کند و محصول/دسته/برند را در دیتابیس متصل به همان WordPress ذخیره می‌کند. هیچ دیتابیس نمونه یا Mock استفاده نمی‌شود.
