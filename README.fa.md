# فروشگاه اینترنتی Bamero برای WordPress و WooCommerce

این مخزن یک قالب سبک و راست‌چین WordPress به نام **Bamero**، محیط توسعهٔ محلی با Docker Compose و چک‌های اولیهٔ CI را نگه می‌دارد. قالب به WooCommerce وابسته است و از سیستم اصلی آن برای کالاها، دسته‌بندی‌ها، جست‌وجوی کالا، سبد، پرداخت و سفارش استفاده می‌کند؛ دادهٔ محصول یا درگاه پرداخت ساختگی در مخزن قرار داده نشده است.

## اجرای محلی

1. Docker و Docker Compose را نصب کنید.
2. `.env.example` را به `.env` کپی کنید. مقادیر داخل فایل نمونه فقط برای کار محلی‌اند؛ پیش از هر محیط عمومی، رمزهای قوی و جداگانه تعیین کنید.
3. `docker compose up -d` را اجرا کنید و راه‌اندازی اولیهٔ WordPress را در `http://localhost:8080` کامل کنید.
4. از پیشخوان به **افزونه‌ها ← افزودن افزونه** بروید و افزونهٔ رسمی WooCommerce را نصب و فعال کنید.
5. از **نمایش ← پوسته‌ها**، پوستهٔ Bamero را فعال کنید. برای رابط فارسی، زبان سایت را از **تنظیمات ← عمومی** روی فارسی قرار دهید.
6. راه‌انداز WooCommerce را تکمیل کنید، صفحات فروشگاه/سبد/تسویه‌حساب را بسازید و سپس کالاهای واقعی و تصاویر مجاز خودتان را وارد کنید.

در Compose، فایل پوسته مستقیماً از مخزن mount می‌شود؛ تغییرات PHP/CSS/JS بلافاصله در نصب محلی دیده می‌شوند. دیتابیس و فایل‌های WordPress در volumeهای Docker نگهداری می‌شوند. این Compose صرفاً محیط توسعهٔ محلی است و reverse proxy، TLS یا پیکربندی production ندارد.

## ساختار

- `wp-content/themes/bamero/`: پوستهٔ سفارشی؛ فایل‌های اصلی WordPress، افزونهٔ WooCommerce و اطلاعات کالا عمداً در Git نیستند.
- `compose.yaml`: WordPress و MariaDB برای توسعهٔ محلی.
- `.github/workflows/theme-ci.yml`: بررسی نحوی PHP و اعتبار JSON در Pull Request و push به شاخهٔ اصلی.
- `docs/launch-checklist-fa.md`: مراحل لازم برای نصب، آزمون و انتشار ایمن.

## آماده‌سازی انتشار

قبل از فروش واقعی، افزونه‌ها و نسخه‌های WordPress/PHP را روی میزبانی معتبر و به‌روز نگه دارید، TLS را اجباری کنید، ایمیل سفارش‌ها را تحویل‌پذیر کنید، روش‌های ارسال/مالیات/ارز/سیاست‌های مرجوعی را مطابق کسب‌وکار و حوزهٔ قضایی خود تنظیم کنید و سفارش‌های آزمایشی را در حالت sandbox درگاه پرداخت انجام دهید. هیچ رمز، کلید درگاه، دادهٔ مشتری یا فایل `.env` را در GitHub commit نکنید. جزئیات کامل در [چک‌لیست انتشار](docs/launch-checklist-fa.md) است.

## وضعیت قابلیت‌ها

قالب شامل خانهٔ فروشگاه با نمایش پویا و آخرین کالاها، پیوند پویا به دسته‌بندی‌های دارای کالا، جست‌وجوی کالا، منوی واکنش‌گرا، نشانگر تعداد اقلام سبد و ظاهر پایهٔ صفحات WooCommerce است. کاتالوگ، صفحهٔ سیاست‌ها، تنظیمات مالیات/ارسال، درگاه و اطلاعات تماس باید توسط مالک فروشگاه تکمیل شوند. نصب افزونهٔ WooCommerce و فعال‌سازی قالب به‌تنهایی فروشگاه را برای دریافت پرداخت واقعی منتشر نمی‌کند.
